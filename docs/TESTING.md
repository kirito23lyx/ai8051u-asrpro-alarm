## 五项调试总结

| 问题 | 本地资料中的排查与处理 | 证据范围 |
| --- | --- | --- |
| UART1 外部模块接收异常 | 比较板间、板载串口和外部模块接收；采用 UART2 P4.2/P4.3 与 ASRPRO 通信 | 参考例程有独立调试文档；最终源码使用 UART2 |
| S0-S7 映射 | 两行分别扫描 S0-S3、S4-S7，纠正按键编号 | 报告调试总结与最终按键源码一致 |
| OLED 排版 | 以 16x16 中文、8x16 ASCII 计算宽度，缩短提示并使用整屏位图 | 报告总结；实物照片显示时间页运行 |
| EEPROM E2/E5 | 比较可保存的参考底层，恢复例程式擦除、写入、读回校验流程 | 报告记录历史问题及处理；当前代码无 E5，最终掉电验收结果未在报告中完整记录 |
| 光敏 ADC | AO 接 PC4、3.3V 供电，按 ADC 范围换算门限 | 报告及实物接线；当前源码门限为 <1862，SDK 确认 PIN 20=PC4 |

五项内容作为历史调试总结，不包装成五次新实测。报告附录部分旧描述与最终源码不同，例如旧 PIN=17 描述；仓库技术说明以当前源码及本机 SDK 为准。

## 报告中的功能测试表

覆盖 OLED 显示、S4 切换、S5 长按、S6/S7 连调、语音命令、到点响铃、EEPROM 恢复及光敏触发。部分结果仅以代码逻辑支持说明，没有测量次数、日期或完整成功记录，不把这些项目统一标为“实测通过”。

报告明确未提供整机功耗、语音识别准确率、长时间走时误差和光照强度阈值的实测数据。后续可按 READINESS.md 的测试表补充。操作视频由作者决定不提供。
