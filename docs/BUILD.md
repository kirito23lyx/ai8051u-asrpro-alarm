# 编译与烧录

## 环境依赖

- Keil uVision 与 **C251**，不能按普通 C51 工程处理。
- STC AI8051U 设备支持，提供 `ai8051u.h`；`intrins.h` 来自工具链。
- AiCube-ISP 下载软件、驱动及天问 Block ASRPRO 图形化开发环境。

这些是本机当前可用版本，不代表每份历史固件都在相同环境构建。AI8051U 设备包没有识别到明确发行版本；芯片头文件已安装。天问主程序资源版本 0.1.0 与安装包发行名不同，环境说明采用安装包发行名。

本机厂商头文件位于 `C251/INC/STC/AI8051U.H`，不随包再分发。若找不到头文件，请安装设备支持并检查 Include Paths。

## 主控

1. 打开 `firmware/ai8051u/project.uvproj`。
2. 确认目标 `AI8051U-32Bit Series`、时钟 40 MHz，保留现有 C251 工程设置。
3. Rebuild，检查错误和警告；新 HEX 输出到 `Objects`。
4. 烧录设置运行 IRC 为 40 MHz、32-Bit 模式，与源码和工程配置一致。EEPROM 需分配覆盖 `0x40` 所在扇区的数据空间；例如预留 1 KB。最终下载软件配置截图待补，Keil 工程不能证明实际烧录选项。
5. 设置闹钟并保存，然后真正断电重启验证。

重新下载时是否擦除 EEPROM 取决于下载软件选项；这与单纯断电恢复是两个测试。工程不依赖 USB CDC，因此无需 `cdc.lib`。

历史 `Objects`、`Listings` 和 IDE 用户布局没有打包，避免旧 HEX 与新源码不一致。

## ASRPRO

导入 `firmware/asrpro/_alarm.hd`，选 ASRPRO 板型，再生成、编译及烧录。串口 PB5 TX、PB6 RX、115200。当前本机 SDK 已确认 PIN 20 是 PC4；门限保持源文件的 `<1862`。
